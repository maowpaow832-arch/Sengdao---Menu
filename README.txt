ເມນູຮ້ານ ແສງດາວ ປີ້ງຫູໝູ
==========================

ໂຄງສ້າງໄຟລ໌
- index.html          ໜ້າເວັບເມນູ (ບໍ່ຕ້ອງແກ້ໄຂ)
- menu.json           ລາຍຊື່ຮູບ (GitHub Action ສ້າງໃຫ້ອັດຕະໂນມັດ)
- menu/               ໂຟນເດີເກັບຮູບເມນູທັງໝົດ
- .github/workflows/  ຕົວສ້າງ menu.json ອັດຕະໂນມັດ

ວິທີເປີດເວັບ (ເຮັດຄັ້ງດຽວ)
1. ສ້າງ repository ໃນ GitHub ແລ້ວອັບໂຫຼດໄຟລ໌ທັງໝົດຂຶ້ນໄປ
2. Settings → Pages → Source: "Deploy from a branch" → ເລືອກ main ແລະ / (root) → Save
3. Settings → Actions → General → Workflow permissions → ເລືອກ "Read and write permissions" → Save
4. ລໍຖ້າ 1-2 ນາທີ ເວັບຈະຢູ່ທີ່ https://ຊື່ຜູ້ໃຊ້.github.io/ຊື່-repo/

ວິທີເພີ່ມ / ລຶບ / ປ່ຽນເມນູ
1. ເປີດໂຟນເດີ menu ໃນ GitHub
2. ກົດ Add file → Upload files ແລ້ວລາກຮູບໃສ່ (ຫຼືກົດຮູບເກົ່າ → ຖັງຂີ້ເຫຍື້ອ ເພື່ອລຶບ)
3. ກົດ Commit changes
4. ລໍຖ້າ 1-2 ນາທີ ເມນູໃນເວັບຈະອັບເດດເອງ

ກົດການຕັ້ງຊື່ໄຟລ໌ (ໃສ່ລາຄາທ້າຍຊື່)
- ອາຫານ:     ຊື່ເມນູ ລາຄາ.jpg          ຕົວຢ່າງ  ຍຳປາໝຶກ 135,000ກີບ.jpg
- ເຄື່ອງດື່ມ:  A-ຊື່ເມນູ ລາຄາ.jpg        ຕົວຢ່າງ  A-BeerLao 26,000ກີບ.jpg
  (ຂຶ້ນຕົ້ນດ້ວຍ A- ຈະເຂົ້າໝວດເຄື່ອງດື່ມ, ເວັບຈະບໍ່ສະແດງ "A-")
- ໄຟລ໌ທີ່ບໍ່ຂຶ້ນຕົ້ນດ້ວຍ A- ຖືວ່າເປັນອາຫານ
- ຮອງຮັບ .jpg .jpeg .jfif .png .webp .gif .avif
- ຊື່ເມນູໃສ່ເຄື່ອງໝາຍ "-" ໄດ້ ລາຄາແມ່ນຕົວເລກທ້າຍຊື່ໄຟລ໌
- ເມນູຈະລຽງຕາມຕົວອັກສອນຂອງຊື່ໄຟລ໌

ເຄັດລັບຮູບ
- ຖ່າຍເທິງພື້ນຂາວ ເວັບຈະລົບພື້ນຂາວອອກໃຫ້ເອງ
- ຮູບ PNG ໂປ່ງໃສ ໃຊ້ໄດ້ເລີຍ
- ຮູບທີ່ບໍ່ມີພື້ນຂາວ ຈະສະແດງເປັນວົງກົມ

ຖ້າເມນູບໍ່ອັບເດດ
- ເບິ່ງແຖບ Actions ໃນ GitHub ວ່າ "update-menu" ເຮັດວຽກສຳເລັດ (ຕິກສີຂຽວ) ບໍ
- ກວດວ່າໄດ້ຕັ້ງ Workflow permissions ເປັນ Read and write ແລ້ວ
- ກົດ Ctrl+F5 (ຫຼືລ້າງ cache) ເພື່ອໂຫຼດໜ້າໃໝ່

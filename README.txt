1) ເປີດເວັບດ້ວຍ GitHub Pages (ເຮັດຄັ້ງດຽວ)
-------------------------------------------
1. ອັບໂຫຼດໄຟລ໌ທັງໝົດຂຶ້ນ repo ໃນ GitHub (ໃຫ້ຢູ່ໃນໂຟນເດີຫຼັກ, ບໍ່ແມ່ນໃນໂຟນເດີຍ່ອຍ)
2. ໄປທີ່ Settings → Pages
3. Source ເລືອກ "Deploy from a branch"
4. Branch ເລືອກ main ແລະ ໂຟນເດີ / (root) ແລ້ວກົດ Save
5. ລໍຖ້າ 1-2 ນາທີ ເວັບຈະເປີດທີ່ https://ຊື່ຜູ້ໃຊ້.github.io/ຊື່-repo/
6. ໄປທີ່ Settings → Actions → General → Workflow permissions
   ເລືອກ "Read and write permissions" ແລ້ວກົດ Save
   (ເພື່ອໃຫ້ GitHub Action ອັບເດດ menu.json ໄດ້)


2) ວິທີເພີ່ມ / ລຶບ / ແກ້ໄຂເມນູ
------------------------------
ເພີ່ມເມນູ:
  - ເຂົ້າໂຟນເດີ menu ໃນ GitHub → Add file → Upload files → ລາກຮູບໃສ່ → Commit changes
  - ເວັບຈະອັບເດດເອງພາຍໃນ 1-2 ນາທີ (ຖ້າບໍ່ເຫັນ ໃຫ້ຣີເຟຣຊໜ້າເວັບ)

ລຶບເມນູ:
  - ເຂົ້າໂຟນເດີ menu → ກົດທີ່ຮູບ → ກົດ ... (ສາມຈຸດ) → Delete file → Commit changes

ແກ້ໄຂຊື່ ຫຼື ລາຄາ:
  - ລຶບຮູບເກົ່າ ແລ້ວອັບຮູບໃໝ່ທີ່ຕັ້ງຊື່ໃໝ່ (ຫຼື ກົດ ... → Rename)

4) ວິທີປ່ຽນຮູບພື້ນຫຼັງ (Background)
-----------------------------------
- ຊື່ໄຟລ໌ຕ້ອງເປັນ  Background.png  ຫຼື  Background.jpg  (ໃຊ້ໄດ້ທັງສອງແບບ)
- ອັບໂຫຼດເຂົ້າໂຟນເດີ Background/  ຖ້າມີທັງ .png ແລະ .jpg ເວັບຈະໃຊ້ .png ກ່ອນ
  (ຖ້າປ່ຽນເປັນນາມສະກຸນອື່ນ ໃຫ້ລຶບໄຟລ໌ເກົ່າອອກ)
- ຕ້ອງເປັນຮູບແນວຕັ້ງ ອັດຕາສ່ວນ 2:3 (ເຊັ່ນ 1024 x 1536 px) ໂລໂກ້ຢູ່ເທິງຂວາ ແລະ ໃບໄມ້ທອງຢູ່ລຸ່ມ
- ຮູບສ່ວນເທິງ (ໂລໂກ້) ແລະ ສ່ວນລຸ່ມ (ໃບໄມ້) ຈະເລື່ອນໄປພ້ອມກັບໜ້າເວັບ
- ຊື່ຮ້ານບໍ່ໄດ້ຂຽນໃນເວັບ ເພາະຢູ່ໃນຮູບພື້ນຫຼັງແລ້ວ
- ຖ້າບໍ່ມີໄຟລ໌ນີ້ ເວັບຈະໃຊ້ພື້ນດຳລາຍທອງແບບເດີມ


5) ວິທີປ່ຽນໄອຄອນ (Icon)
-----------------------
ໄຟລ໌ໃນໂຟນເດີ Icon/ (ນາມສະກຸນ .png ຫຼື .jpg ໃຊ້ໄດ້ທັງສອງ):
  Food.png     ໄອຄອນໝວດອາຫານ
  Drink.png    ໄອຄອນໝວດເຄື່ອງດື່ມ
  Back.png     ໄອຄອນປຸ່ມ "ກັບຄືນ"
  Favicon.png  ໄອຄອນຂອງແທັບເວັບ (ບໍ່ບັງຄັບ)
- ຊື່ໄຟລ໌ຕ້ອງຖືກ: ຕົວອັກສອນທຳອິດເປັນໂຕໃຫຍ່ (Food, Drink, Back)
- ແນະນຳ .png ພື້ນໂປ່ງໃສ (ບໍ່ມີພື້ນສີຂາວ/ດຳ). ຖ້າໃຊ້ .jpg ພື້ນດຳ ເວັບຈະເຮັດໃຫ້ພື້ນດຳກົມກືນກັບພື້ນຫຼັງ
- ຖ້າມີທັງ .png ແລະ .jpg ຊື່ດຽວກັນ ເວັບຈະໃຊ້ .png ກ່ອນ
- ຖ້າບໍ່ມີໄຟລ໌ໃດ ເວັບຈະສະແດງ emoji ແທນ (🍽️ 🥤 ←)


6) ການໃຊ້ງານໜ້າເມນູ
-------------------
- ໜ້າເມນູລວມສະແດງສະເພາະຮູບ ກົດທີ່ຮູບເພື່ອເບິ່ງຊື່ ແລະ ລາຄາ
- ຮູບຈະຂະຫຍາຍໄປຝັ່ງຊ້າຍ ແລະ ຊື່/ລາຄາຢູ່ຝັ່ງຂວາ (ແບ່ງ 50/50)
- ປິດໂດຍກົດປຸ່ມ "← ກັບຄືນ", ກົດພື້ນທີ່ຫວ່າງ ຫຼື ກົດປຸ່ມ Esc


7) ແກ້ບັນຫາເບື້ອງຕົ້ນ
---------------------
- ອັບຮູບແລ້ວບໍ່ຂຶ້ນ: ລໍຖ້າ 1-2 ນາທີ ແລ້ວຣີເຟຣຊ. ກວດວ່າຊື່ໄຟລ໌ຖືກກົດ ແລະ ນາມສະກຸນຖືກຕ້ອງ
- ເຫັນໄອຄອນ emoji ແທນຮູບ: ຮູບຍັງບໍ່ຖືກເຜີຍແຜ່ ຫຼື ຊື່ໄຟລ໌ຜິດ (ຊື່ໄຟລ໌ຕ້ອງຕົງຕາມ ໂຕໃຫຍ່-ໂຕນ້ອຍ)
- ປ່ຽນໄຟລ໌ແລ້ວແຕ່ເວັບຍັງເປັນແບບເກົ່າ: ລໍ 1-2 ນາທີ ແລ້ວກົດ Ctrl+F5 (ມືຖື: ປິດແທັບແລ້ວເປີດໃໝ່)
- menu.json ບໍ່ອັບເດດ: ກວດ Settings → Actions → General → Workflow permissions
  ວ່າເປັນ "Read and write permissions" ແລະ ເບິ່ງແຖບ Actions ວ່າມີຂໍ້ຜິດພາດບໍ
- ຕ້ອງການສັ່ງ Action ເອງ: Actions → Update menu.json → Run workflow
- ຖ້າເປີດໄຟລ໌ index.html ໂດຍກົງໃນຄອມ (ບໍ່ຜ່ານ GitHub Pages) ລາຍຊື່ເມນູຈະອ່ານຈາກ menu.json
  ແລະ ການລົບພື້ນຂາວອາດບໍ່ເຮັດວຽກ. ໃຫ້ທົດສອບຜ່ານ GitHub Pages ຫຼື server ໃນເຄື່ອງ
